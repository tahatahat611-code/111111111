# CYBER DEFENSE ACADEMY

منصة ويب تعليمية تفاعلية متعددة الصفحات حول حماية البيانات وأمن أنظمة تكنولوجيا المعلومات.

## التشغيل
- افتح `index.html` مباشرة في المتصفح، أو استخدم Live Server / أي خادم محلي.
- لا تحتاج المنصة إلى Backend أو قاعدة بيانات.
- التقدم وXP والاختبار والملاحظات تحفظ محليًا في `localStorage`.

## الصفحات
- `index.html` شاشة الإقلاع.
- `dashboard.html` لوحة التحكم وخريطة الأمن.
- `labs.html` المختبرات والمحاكاة.
- `game.html` اللعبة الرئيسية 10 مهام.
- `quiz.html` اختبار نهائي 20 سؤالًا عشوائيًا من بنك 30 سؤالًا.
- `research.html` مركز البحث وحفظ الملاحظات.
- `glossary.html` قاموس المصطلحات والبحث الداخلي.
- `videos.html` أماكن الفيديو + scripts.
- `report.html` التقرير النهائي.
- `settings.html` الإعدادات.

## تقسيم التقنية
- HTML متعدد الصفحات.
- `css/style.css` التصميم.
- `js/data.js` البيانات الأكاديمية والمهام والمصطلحات والأسئلة.
- `js/app.js` واجهة المنصة، المختبرات، البحث، التقرير، الإعدادات.
- `js/game.js` اللعبة الرئيسية.
- `js/quiz.js` الاختبار النهائي.
- `assets/` أماكن الصور والفيديو والأيقونات.

## ملاحظة أكاديمية
المصدر المرسل لا يحتوي تفاصيل محددة عن أسعار أو خصائص تجارية لمنتجات Kaspersky/McAfee/AVG/Norton، لذلك لم تتم إضافتها كحقائق. مختبر المقارنة يضع خانات `Requires external research` حتى يتم ملؤها لاحقًا بمصادر بحثية حقيقية إذا طلب المعلم ذلك.
